# Python Collections

## List

- Ordered
- Mutable: values can be changed
- Allows duplicate values
- Supports indexing

Example:

```python
numbers = [10, 20, 30, 20]
numbers[0] = 15
```

## Tuple

- Ordered
- Immutable: values cannot be changed after creation
- Allows duplicate values
- Supports indexing

Example:

```python
numbers = (10, 20, 30)
print(numbers[1])
```

## Set

- Stores unique values only
- Mutable: values can be added or removed
- Does not support indexing
- Has no guaranteed order

Example:

```python
numbers = {10, 20, 30, 20}
numbers.add(35)
```
